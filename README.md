# Pokemon-like Java Game
Dieses Projekt ist ein rein privates Lernprojekt zu Bildungszwecken, um Programmierkonzepte in Java (Objektorientierung, Schleifen, Logikkapselung) zu vertiefen. 
### Rechtlicher Hinweis / Disclaimer
Pokémon ist eine eingetragene Marke von Nintendo, Game Freak und Creatures. Dieses Projekt steht in keiner Verbindung zu diesen Unternehmen. Es handelt sich um eine nicht-kommerzielle Fan-Arbeit. Es werden keine originalen Assets (Grafiken, Sounds) verwendet oder vervielfältigt.
